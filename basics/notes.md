=> What is react js ?
-> React js is a javascript library use to build a single page application


=> library v/s framework
-> framework :- structure provide krta hai (ex. bana banaya ghar kharid liya)
-> library :- predefined block of code (ex. ghar ke coloumn banaye , deewar banayi , slap dale , matlab jo chaiye wo le liya apne hisab se)


=> virtual dom v/s real dom
-> real dom :- actual dom
-> virtual dom :- copy of real dom 

=> what is Diffing in react ?
Diffing is the process where React compares the newly generated Virtual DOM tree with the previous one to figure out exactly what changed in the UI (React compares the old Virtual DOM with the new Virtual DOM.)


=> Reconciliation in react ?
-> Reconciliation is React's process for figuring out what has changed between renders and updating the browser's actual DOM efficiently (React figures out what actually needs to change in the real DOM and applies those changes.)


=> export and import 
-> export :- default and named 
default - ek js file mai ek hi default export kr sakte hu (default export mai aap usko kisi bhi nam se import kar sakte ho)
named - multiple export kr sakte hai
